youtube-manager — Política de Privacidade

Última atualização: 3 de outubro de 2026

O youtube-manager é uma ferramenta de uso exclusivo do canal Harpa Cristã Partituras, operada pelo próprio dono do canal. Não é oferecida a outros usuários.

Dados acessados

Com a autorização do dono do canal, a ferramenta usa as APIs do Google para:

  • YouTube Data API: ler e responder comentários, moderar comentários e gerenciar vídeos do próprio canal;
  • YouTube Analytics API: ler métricas de desempenho do próprio canal;
  • Google Drive API (escopo drive.file): criar e compartilhar arquivos PDF de partituras criados pela própria ferramenta.

Armazenamento e compartilhamento

Os tokens de acesso ficam armazenados apenas no computador do dono do canal ou em ambientes privados controlados por ele. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. Comentários públicos lidos pela ferramenta são usados apenas para responder ao público do canal.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta usa os Serviços de API do YouTube; veja também a Política de Privacidade do Google.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
